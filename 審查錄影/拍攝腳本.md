## 開拍（雙擊「開始錄影.bat」，3 秒後開始）

### 場景 1｜App 身分（10 秒）
1. 打開 PuffinPuff 主視窗
2. 停在首頁 2 秒（讓側欄版本號入鏡）

### 場景 2｜Meta OAuth 完整流程 ⭐ 最重要（90 秒）
> 涵蓋：public_profile、pages_show_list、business_management、
> instagram_basic、Business Asset User Profile Access

1. 側欄 →「帳號」
2. 把現有 Facebook 連線「解綁」（為了示範完整 OAuth）
3. 點 Facebook 卡片「連線」
4. **OAuth 視窗出現 → 放慢：讓權限清單畫面停留 3 秒 → 按繼續/允許**
5. 回到帳號頁：看到 FB 粉專 + 連動的 IG 帳號出現（各停 2 秒）
6. 對 FB 帳號按一下「🔍 測試」→ 等綠色通知出現

### 場景 3｜發布圖文到 FB + IG（90 秒）
> 涵蓋：pages_manage_posts、instagram_content_publish

1. 側欄 →「發布」→ 模式選「🖼 單圖貼文」
2. 拖入桌面的測試圖片
3. 填標題/描述（隨意，例如 "PuffinPuff demo post"）
4. 平台確認 Facebook + Instagram 開啟
5. 按「發布」→ **等進度條跑完、兩個平台都打綠勾**（這段全程入鏡）
6. 點成功後顯示的貼文連結（開瀏覽器看到貼文，停 3 秒）

### 場景 4｜歷史頁數據（30 秒）
> 涵蓋：pages_read_engagement

1. 側欄 →「歷史」
2. 打開剛發布的紀錄 → 按「抓取數據」
3. 讚/留言/觸及數字出現（停 3 秒）
