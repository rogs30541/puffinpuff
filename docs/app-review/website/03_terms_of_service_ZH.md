## 一、服務說明

PuffinPuff 是由 **VVLEE** 開發的 Windows 桌面工具，協助使用者將短影音檔案一次同步發布至下列平台：

- YouTube Shorts（透過 YouTube Data API v3）
- Facebook Reels（透過 Meta Graph API）
- Instagram Reels（透過 Meta Graph API）

本應用程式**完全在使用者電腦本機執行**，沒有伺服器、不收集使用者資料、不在雲端儲存任何資訊。詳見[隱私權政策](https://mememaker-tw.com/puffinpuff/privacy/)。

## 五、API 配額與限制

各平台對其 API 設有用量配額。配額由您所連結的帳號擁有，**不由 PuffinPuff 控管**：

| 平台 | 預設限制 |
|---|---|
| YouTube | Data API quota: 10,000 點/日（一次上傳約 1,600 點） |
| Facebook | Rate limit: 200 calls / hr / token |
| Instagram | Reels API: 25 個 container / 24 hr / 帳號 |

若您超出配額，平台會拒絕後續請求，PuffinPuff 會將該次發布標為「失敗」並顯示對應錯誤訊息。
