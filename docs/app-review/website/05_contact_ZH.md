## 你可能想問的事

### 1️⃣ 帳號 / 授權問題
- OAuth 登入失敗、token 過期、解除授權後再連結
- 某平台某帳號發布失敗
- 想連結多個帳號

### 2️⃣ 排程 / 發布問題
- 排程時間不準、跳週末邏輯
- 影片格式被某平台拒絕
- 重新發布、重新排程操作

### 3️⃣ 隱私 / 資料權利
- 想完整刪除我所有的資料 → 參考 [資料刪除說明](https://mememaker-tw.com/puffinpuff/data-deletion/)

- 回報疑似資料外洩（請於 24 小時內通知我們）

### 4️⃣ 商業合作 / 客製化
- 工作室或公司行號的批量授權
- API 串接、特殊客製化需求

### 5️⃣ 回報 bug / 建議新功能
- bug：請附上 PuffinPuff 版本號（設定頁底部）、Windows 版本、重現步驟
