# PuffinPuff v0.7.0｜Threads 整合規劃

> 加入 Meta Threads 為第四個發布平台。

---

## 1. Threads API 概況

- **Domain**：`graph.threads.net`（**不同於** `graph.facebook.com`）
- **OAuth**：獨立 OAuth flow（不能共用 FB/IG token）
- **Permissions**：`threads_basic`（讀）、`threads_content_publish`（寫）
- **Token**：短效（1 小時）→ 換長效（60 天）
- **發布 Container 流程**：跟 IG Reels 結構**幾乎相同**
  1. POST `/{user-id}/threads`（含 media_type + text + media_url）→ 取得 container_id
  2. GET `/{container-id}?fields=status` 輪詢直到 `FINISHED`
  3. POST `/{user-id}/threads_publish?creation_id=...` → 發布

### 支援的 media_type
- `TEXT`（純文字，up to 500 字）
- `IMAGE`（單張圖 + 可選文字）
- `VIDEO`（單支影片 + 可選文字）
- `CAROUSEL`（2-20 張媒體，圖文混搭）

### 規格限制（2026-05）
- 文字：500 字（**比 IG 短很多**）
- 圖片：JPG / PNG，1080×1080 ~ 1080×1350 建議
- 影片：MP4，最長 5 分鐘，9:16 / 1:1 / 4:5
- Carousel：2-20 張

## 2. 整合架構（在 PuffinPuff 現有架構下）

```
PublishContent.perPlatform.threads: ThreadsContent  ← 新增
  - enabled: boolean
  - accountId?: number
  - includeText: string  ← Threads 字數限制 500，自動截短

Platform = 'youtube' | 'facebook' | 'instagram' | 'threads'  ← 加 'threads'

Account.platform = 'threads'  ← DB 已是 TEXT，不需 migration
```

## 4. ⚠️ VVLEE 你要先做的（不能我代勞）

### Step A：在 Meta 建 Threads App
1. 開 https://developers.facebook.com/apps/804343579328970/use_cases/
   （沿用現有 PuffinPuff v2 App，**不另建**）
2. 「Add product」找 **Threads API**
3. 啟用

### Step B：設 Threads Redirect URI
4. Threads API → Settings → 加入 `https://localhost/puffinpuff-threads-callback`

### Step C：拿 Threads-specific 資訊
5. Threads API → Settings 看：
   - **Threads App ID**（通常 = 主 App ID `804343579328970`）
   - **Threads App Secret**（**可能跟主 App Secret 不同**）

### Step D：把 Threads 業務帳號加入測試者
6. App Dashboard → Roles → **Threads Testers**
7. 加入你 Threads 帳號的 username

## 7. 已知限制 / 注意事項

- ⚠️ Threads API 在 Dev mode 也可能有跟 IG 一樣的 graceful degradation
  → 若遇到，跟 IG 一樣等 Meta App propagation 或走 App Review
- ⚠️ Threads 文字 500 字上限，比 IG/FB 短很多
  → PuffinPuff 會自動把 description + hashtags 截短
- ⚠️ Threads 不接受純 video URL（無 caption 也要 text）
  → adapter 會用 title 當 fallback
