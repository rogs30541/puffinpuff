# A 模式：配對檔案命名規則

> A 模式是「圖文配對」最直觀的批量輸入方式：每篇貼文 = 1 個圖檔 + 1 個 .txt 文字檔，**同名配對**。
> 適合不想學 CSV 格式、用 ChatGPT 生成內容後直接存檔的使用者。

---

## 一句話原則

**圖檔跟文字檔的「副檔名前的名字」要完全一樣。**

```
001.jpg + 001.txt        ✅
001.jpg + 001.TXT        ✅（大小寫不重要）
001-勞資地雷.jpg + 001-勞資地雷.txt   ✅
001 勞資地雷.jpg + 001 勞資地雷.txt   ✅（有空格也 OK）
001-勞資地雷.jpg + 001-員工薪資.txt   ❌（名字不一樣 = 配對失敗）
```

---

## 推薦命名格式

### 格式 1：純編號（最簡單）
```
001.jpg / 001.txt
002.png / 002.txt
003.jpg / 003.txt
...
030.jpg / 030.txt
```

優點：排序最穩、不會排錯
缺點：看不出主題

### 格式 2：編號 + 主題（推薦 ★）
```
001_企業勞資地雷1.jpg / 001_企業勞資地雷1.txt
002_企業勞資地雷2.jpg / 002_企業勞資地雷2.txt
03_員工薪資Q1.png / 03_員工薪資Q1.txt
04_員工薪資Q2.jpg / 04_員工薪資Q2.txt
```

優點：在檔案總管掃就知道內容
缺點：稍微多打字

### 格式 3：日期 + 主題（適合「明確排定特定日期」場景）
```
2026-06-01_企業勞資地雷1.jpg / 2026-06-01_企業勞資地雷1.txt
2026-06-02_企業勞資地雷2.jpg / 2026-06-02_企業勞資地雷2.txt
```

> ⚠️ 注意：A 模式的**檔名日期不會被自動讀為排程時間**。實際排程時間由 PuffinPuff Modal 內統一設定（每日定時 / 間隔模式）。檔名日期只是給你自己看的整理用。
> 想要「每篇指定不同時間」要用 B 模式 CSV。

## 支援的圖片副檔名

| 副檔名 | 支援 | 備註 |
|---|---|---|
| `.jpg` / `.jpeg` | ✅ | 最通用 |
| `.png` | ✅ | 適合有透明背景 / 文字清楚 |
| `.webp` | ✅ | 檔案小但相容性略差 |
| `.gif` | ✅（單張）| 動圖會被當第一格 |
| `.heic` | ❌（暫不支援）| iPhone 預設格式，需先轉成 jpg |
| `.bmp` / `.tiff` | ❌（暫不支援）| 平台不接受 |

> iPhone 拍照預設 .heic → 用 iPhone 內建「複製到資料夾」會自動轉 jpg，或用 [https://heic.gallery/](https://heic.gallery/) 批量轉。

## .txt 文字檔內容格式

`.txt` 檔**整個檔案內容 = 該篇貼文的完整 caption**（含標題、內文、hashtag）。

### 最簡單格式
```
今天分享 5 個提升效率的小技巧。

第一招：番茄鐘工作法
第二招：批次處理同類任務
第三招：清空收件匣
第四招：每週回顧
第五招：說「不」

你常用哪一招？留言告訴我。

#工作術 #效率 #自我成長 #職場 #時間管理
```

### 進階格式（推薦）

加入分區標記讓內容更結構化：

```
【企業勞資地雷】違法解雇

最近又有老闆問我：「員工不適任就直接 fire 不行嗎？」

答案是：99% 不行。

依《勞基法》第 11 條，雇主終止契約需符合「五大法定事由」之一：
1. 業務緊縮
2. 不可抗力暫停工作 1 個月以上
3. 業務性質變更
4. 對所擔任工作確不能勝任
5. ...

且第 4 項「不能勝任」要有完整的：
✓ 績效紀錄
✓ 多次輔導文件
✓ 改善期間

少一項就有違法解雇風險，賠償金額最少 6 個月薪資。

💡 給老闆的建議：
解雇前先諮詢專業，省下 50 萬以上潛在賠償。

📩 想知道你公司的解雇程序合不合法？預約 30 分鐘免費諮詢：
[https://lin.ee/yourshortcut]

#勞資顧問 #違法解雇 #勞動法 #企業軍師 #林郁汶
#中小企業 #人資 #勞動爭議 #職場法律 #雇主必看
```

## 文字檔編碼要求

⚠️ **務必存成 UTF-8 編碼**，不然中文會亂碼。

### Windows 記事本
1. 寫完內容
2. 點「**另存新檔**」
3. 編碼下拉選「**UTF-8**」（不要選「ANSI」或「UCS-2」）
4. 存檔

### VS Code / Sublime / 其他編輯器
預設都是 UTF-8，直接存即可。

### ChatGPT 複製貼上時的小提醒
- ChatGPT 網頁複製出來預設 UTF-8 → 貼進記事本 → 另存 UTF-8 → OK
- 用 ChatGPT macOS App 複製出來注意有時會夾帶「Smart Quotes」全形引號 → 用「取代」改回半形

## PuffinPuff 偵測規則

當你拖入資料夾，PuffinPuff 會：

1. **掃資料夾**找所有 `.jpg / .jpeg / .png / .webp / .gif` 檔
2. **配對 .txt**：每個圖檔找「同名 .txt」
   - 有配對 → 該篇貼文
   - 沒配對 → 跳過該圖檔（顯示警告）
3. **排序**：按檔名英文字典排序（自然順序，001 在 010 前面，所以建議補零）
4. **依排程規則分配時間**：你在 Modal 設「每天 20:00、每 1 天一篇」→ 第 1 篇排明天 20:00、第 2 篇後天 20:00…

## 排程模式對應（A 模式專屬）

A 模式只支援**間隔批量排程**（同模式下所有篇用同一規則）：

| 排程模式 | 適合 |
|---|---|
| **每日定時**（每天 20:00、每 N 天 1 篇、可跳週末） | 主力使用 |
| **間隔模式**（從現在起每 X 小時 1 篇） | 短時間連發 / 補洞 |
| **每天 N 篇定時**（每天 10:00 + 14:00 + 20:00 各 1 篇） | 高產量 |

時間規則由 PuffinPuff Modal 內**統一設定**，每篇套用同一規則依檔名順序分配。

**想要每篇單獨指定時間 / 平台 / hashtag 嗎？** 用 B 模式 CSV manifest（看下一份）。

## 常見問題 FAQ

### Q：我可以混入沒有 .txt 配對的圖嗎？
A：可以，**沒配對的圖會被跳過**並在預覽顯示警告。不影響其他配對的圖正常排程。

### Q：我可以混入沒有圖的 .txt 嗎？
A：可以，**沒配對的 .txt 會被跳過**。

### Q：同一個資料夾可以包含 30 篇圖文 + 5 支影片嗎？
A：不行。圖文模式只掃 jpg/png 圖檔，**忽略 mp4 等影片檔**。
影片要走「批量影片模式」（拖入另一個資料夾）。

### Q：30 篇圖文要花多少時間在 PuffinPuff 上設定？
A：拖入 + 預覽 + 設排程規則 + 確認 < 5 分鐘。

### Q：可以中途改某 1 篇 caption 嗎？
A：可以，**在 Modal 預覽列表上點該行 → 編輯 caption**（單篇覆寫）。
但這只在當次匯入有效，下次重新拖資料夾要重新編輯。
想要永久改 → 改 `.txt` 檔案內容 + 重新拖入。

### Q：我用 Mac / iPhone 編輯 txt 檔，PuffinPuff 是 Windows 看得到嗎？
A：可以。.txt UTF-8 是跨平台通用格式。但檔名最好避免 emoji / 特殊符號。
