# ChatGPT Prompt 模板｜一次生成 30 篇不同 caption

> 直接複製對應模板貼到 ChatGPT / Claude，把 `[變數]` 換成你的內容，就會一次吐出 N 篇貼文。

---

## 通用 Meta Prompt（先建立角色）

每次開新對話前先貼這段：

```
你是「{你的品牌}」的社群編輯，負責為這個品牌寫 Facebook 粉專 + Instagram Feed 圖文貼文。

品牌定位：{一句話描述，例：勞資領航者・企業軍師 林郁汶。專業勞資顧問，
專為中小企業老闆解決勞動法問題。}

語氣 / 風格：{例：專業但親民、知識感重、用台灣繁體中文、適量使用 emoji（但不過量）、
避免艱深法律用語、必要時用比喻或案例輔助。}

每篇貼文目標：建立專業信任 → 引導讀者「想知道更多就找我諮詢」

每篇貼文結構（嚴格遵守）：
1. 標題：1 行，最多 25 字，要有 hook（疑問、震驚、好奇）
2. 內文：3-5 段，每段 2-3 句話，段與段中間空 1 行
3. CTA：最後 1 行加「想知道更多？預約 30 分鐘免費諮詢 → [LINE OA 連結]」
4. Hashtag：5-8 個，混合「品牌類」（如 #勞資顧問）+「主題類」（如 #資遣費）+「行為類」（如 #小企業必看）

字數限制：
- IG caption 中文不超過 250 字（不含 hashtag）
- FB 貼文不限制但建議 200-400 字

我接下來會告訴你主題系列，請一次生成所有貼文。
```

## 模板 1：「N 個 X」清單系列

```
請依照前面設定的角色與規範，生成「{主題}」清單系列共 {N} 篇貼文。

主題：{企業勞資地雷}
數量：{10}

要求：
- 每篇講 1 個地雷（編號 1-{N}）
- 每篇結構：
  • 標題：「企業勞資地雷 N：[地雷名稱]」
  • 內文：1 段描述地雷是什麼、1 段為什麼會踩、1 段如何避免
  • CTA：固定（前述）
  • Hashtag：5-8 個

把 10 篇用「---」分隔，每篇最上面標「===== 第 N 篇 =====」。

開始生成。
```

## 模板 2：「Q&A 問答」系列

```
請依照前面設定的角色與規範，生成「{主題}」Q&A 問答系列共 {N} 篇貼文。

主題：{員工常問的薪資問題}
數量：{20}

要求：
- 每篇 1 組 Q&A
- 問題要是讀者實際會用的口語問法，不是教科書式提問
- 每篇結構：
  • 標題：「Q{N}：[問題]」（問題要短、有梗）
  • 內文：
    - 「先給你答案：」+ 1 句結論
    - 「為什麼是這樣：」+ 2-3 段解釋
    - 「實際例子：」+ 1 個具體案例
  • CTA：固定
  • Hashtag：5-8 個

把 20 篇用「---」分隔，每篇最上面標「===== Q{N} =====」。

請先給我 20 個問題清單讓我確認，確認後我說「生成」你才開始展開所有內文。
```

## 模板 3：「對比」系列

```
請依照前面設定的角色與規範，生成「{主題}」合法 vs 違法對比系列共 {N} 篇貼文。

主題：{勞動條件對照}
數量：{30}

要求：
- 每篇 1 組對比
- 每篇結構：
  • 標題：「✅ 合法 vs ❌ 違法：[對比主題]」
  • 內文（用兩欄式但純文字實作）：
    - 「❌ 違法做法：[描述]」
    - 「✅ 合法做法：[描述]」
    - 「為什麼：[法條 + 解釋]」
    - 「給老闆 / 主管的建議」
  • CTA：固定
  • Hashtag：5-8 個

開始生成 30 篇。
```

## 模板 4：「案例分析」系列

```
請依照前面設定的角色與規範，生成「{主題}」真實案例分析系列共 {N} 篇貼文。

主題：{勞資爭議真實案例（去識別化）}
數量：{10}

特別說明：
- 你不需要查真實案例，可以依「常見類型」設計合理案例
- 但要寫得像真的，包含時間、產業、人數等細節
- 絕對不出現真實人名 / 公司名

每篇結構：
- 標題：「案例 N：[case 主題]」（要有 hook，例：「資遣 50 萬翻盤？這個老闆的失誤」）
- 內文：
  • 背景設定（產業、規模、角色）3-4 句
  • 衝突發生（什麼事件觸發爭議）2-3 句
  • 雙方主張（員工說 vs 老闆說）2-3 句
  • 法律見解 / 法院判斷 3-4 句
  • 給看貼文人的啟示 2-3 句
- CTA：固定
- Hashtag：5-8 個

生成 10 篇。每篇用「---」分隔。
```

## 模板 6：「步驟教學」系列

```
請依照前面設定的角色與規範，生成「{主題}」步驟教學系列共 {N} 篇貼文。

主題：{30 天建立完整勞動契約}
數量：{30}

要求：
- 每篇 1 個步驟（Day 1 - Day 30）
- 步驟之間要有邏輯遞進
- 每篇結構：
  • 標題：「Day N：[今天要做的事]」
  • 內文：
    - 「為什麼今天做這個」1 段
    - 「具體 3 步驟」分點列
    - 「完成後勾選 ☐ [完成事項]」
  • CTA：固定
  • Hashtag：5-8 個

請先給我 30 天的步驟大綱（每天標題 + 1 句概要），讓我確認順序合理，確認後我說「生成」你才展開所有內文。
```

## 模板 7：「時事評論」系列

```
請依照前面設定的角色與規範，為以下時事撰寫 1 篇分析貼文：

時事：{貼上新聞標題 + 連結 + 摘要}

要求：
- 用時事當引子（不要直接讚揚或批評當事人）
- 帶出可長期適用的法規知識點
- 結尾不下政治判斷
- 結構：
  • 標題：「[時事關鍵字] - 老闆 / 員工該注意什麼？」
  • 內文：
    - 「事件概要」1 段（中性描述）
    - 「從勞動法角度看」2-3 段分析
    - 「對你 / 你的公司的影響」1 段
    - 「實務建議」1 段
  • CTA：固定
  • Hashtag：5-8 個（含時事關鍵字 + 品牌 hashtag）

生成 1 篇。
```

> 時事系列建議每週 1 篇即可，不要批量生成（時事每天都變）。

## 模板 9：通用「批量改寫」prompt（已有舊內容、想批量重寫）

```
我有 30 篇舊貼文，想批量改寫成更符合「{你的品牌}」現在的風格。

舊貼文清單（用「---」分隔）：
[貼進去 30 篇]

請依照前面設定的角色與規範，把每篇重寫一次。
保留原意但：
- 標題重寫得更有 hook
- 內文結構統一（標題 / 段落 / CTA / Hashtag）
- 統一品牌 hashtag
- 補充欠缺的法規依據（若有）

把改寫後 30 篇用「---」分隔，每篇前標「===== 第 N 篇（原：[舊標題]）=====」。
```

我有 1 篇貼文，要發到 FB 粉專 + IG Feed。但 FB 用戶偏老闆 / 中年、IG 用戶偏年輕員工 / 上班族。
想要兩個平台同主題但角度不同的版本。

原文：
[貼進去]

請給我：
1. FB 版本（針對老闆視角，可能稍微多一點法律語言、更務實）
2. IG 版本（針對員工 / 年輕族群，多一點生活感、emoji 多一點、Hashtag 更社群化）

## 使用建議

### 第一次用 → 先試模板 2（Q&A）
最簡單、ChatGPT 最容易展開、貼文之間差異最明顯。

### 累積 3-6 個月內容 → 用模板 6（步驟教學）
能在 30 天內構建完整品牌知識體系。

### 想要批量、又怕重複 → 用模板 1（清單）
30 個地雷、20 個迷思，題材有限但結構穩定。

### 寫到沒梗 → 用模板 9（批量改寫舊文）
把過去半年的貼文翻新一輪，等於賺到 30 篇新內容。

## ChatGPT vs Claude vs Gemini

| 工具 | 適合場景 |
|---|---|
| **ChatGPT GPT-4o / GPT-5** | 中文流暢度最佳，台灣語境 OK，建議主力 |
| **Claude Sonnet 4.7+** | 邏輯結構最強，「步驟教學」「對比」系列最適合 |
| **Gemini 2.0 Pro+** | 免費額度多，可用來做「批量改寫」省 token |

---

## 一次生成 30 篇的小技巧

1. **分批生成**：30 篇一次可能會被截斷，建議分 3 批 × 10 篇
2. **要求 markdown 輸出**：每篇加 `=====` 分隔，方便複製出來分檔
3. **確認大綱再展開**：先讓 AI 給你 30 個標題清單，確認後才展開內文
4. **保留版本**：把整段 ChatGPT 對話複製存檔，下個月可以「再給我 30 篇類似結構但不同主題」省 prompt
