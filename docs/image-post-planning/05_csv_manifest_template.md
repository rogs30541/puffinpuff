# B 模式：CSV manifest 範本與使用指南

> B 模式是「精確控制」批量輸入方式：每篇圖文可獨立指定時間、平台、caption、hashtag。
> 適合進階使用者、需要逐篇排時間或選平台、用 Excel / Google Sheets 集中管理的場景。

---

## B 模式啟用條件

PuffinPuff 拖入資料夾時，會自動偵測：

| 資料夾結構 | 採用模式 |
|---|---|
| 資料夾根層有 `manifest.csv` | **B 模式**（讀 CSV 控制全部）|
| 資料夾根層**沒有** `manifest.csv` | A 模式（配對檔案）|

所以要切到 B 模式，**只需在你的圖文資料夾根層放一個 `manifest.csv`**。

---

## manifest.csv 標準格式

### 第一行：欄位名稱（**必須照順序**）

```csv
filename,caption,hashtags,platforms,scheduled_at
```

### 第二行起：每行 = 1 篇貼文

```csv
001.jpg,"今天分享 5 個小技巧...","#工作術 #效率","fb,ig","2026-06-01 20:00"
002.png,"員工薪資 Q&A...","#勞資 #薪資","ig","2026-06-02 09:30"
03-海邊.jpg,"夏日感悟","#旅行","fb","2026-06-03 14:30"
```

---

## 5 個欄位詳解

### 1. `filename`（必填）
- 圖檔的**檔名**（**不含路徑**，因為已經在資料夾內）
- 支援：`.jpg / .jpeg / .png / .webp / .gif`
- 大小寫不重要（Windows 不分大小寫）
- 範例：`001.jpg` / `海邊.png` / `03_勞資1.jpg`

### 2. `caption`（必填）
- 該篇貼文的完整文字（**不含 hashtag**）
- **必須用雙引號包起來**（因為內容會包含逗號）
- 換行用 `\n`（CSV 標準）或保留實際換行（Excel 會自動處理）
- 不要在 caption 內放 hashtag → 那是下一欄

範例：
```csv
"今天分享 5 個小技巧。\n\n第一招：番茄鐘\n第二招：批次處理\n\n你常用哪一招？"
```

### 3. `hashtags`（必填，可空字串 `""`）
- 該篇貼文的 hashtag，**空白分隔**
- 每個 hashtag 必須有 `#` 開頭
- 範例：`#勞資 #薪資 #職場 #雇主必看`

### 4. `platforms`（必填）
- 該篇要發布到哪些平台，**逗號分隔**
- 支援值：`fb` / `ig`（不分大小寫）
- **不支援** `yt`（圖文不適用 YouTube）
- 範例：
  - `fb,ig` — 同時發 FB + IG
  - `fb` — 只發 FB
  - `ig` — 只發 IG

### 5. `scheduled_at`（必填）
- 該篇要排定的發布時間，格式 `YYYY-MM-DD HH:MM`
- 時區用**台灣時區（GMT+8）**
- 必須是未來時間（過去時間會被 PuffinPuff 標警告）

範例：
- `2026-06-01 20:00` ✅
- `2026/06/01 20:00` ✅ 也接受
- `2026-06-01T20:00:00+08:00` ✅ ISO 8601 也接受
- `6/1 8pm` ❌ 不接受口語格式

## 用 Excel 編輯的步驟

### 1. 新建 Excel
- 開 Excel → 第 1 列輸入欄位名（filename / caption / hashtags / platforms / scheduled_at）
- 第 2 列起每列 1 篇貼文

### 2. 填入內容
- caption 含換行：在 cell 內按 `Alt + Enter` 換行
- platforms：直接輸入 `fb,ig` 或 `fb`
- scheduled_at：先把欄位格式設為「文字」（避免 Excel 自動轉日期格式），再輸入 `2026-06-01 20:00`

### 3. 另存為 CSV
- 「**檔案 → 另存新檔**」
- 檔案類型選「**CSV UTF-8 (逗號分隔) (*.csv)**」⚠️ 一定要選 UTF-8 那個
- 檔名：`manifest.csv`
- 存到你的圖文資料夾根層

### 4. 驗證 CSV
- 用記事本打開 `manifest.csv`
- 看內容是不是符合 `filename,caption,hashtags,platforms,scheduled_at` 格式
- 中文沒亂碼 → OK

## 用 Google Sheets 編輯

### 1. 開 Google Sheets
- 在 Google Drive 新增「試算表」
- 同樣填入欄位名 + 30 列內容

### 2. 匯出 CSV
- 「檔案 → 下載 → 逗號分隔值 (.csv)」
- 自動 UTF-8 編碼，不會亂碼

### 3. 改名 `manifest.csv` 放進資料夾

## CSV 陷阱與避免技巧

### 陷阱 1：caption 含雙引號
```csv
❌ "他說：「沒問題」"      ← 雙引號裡又有雙引號（CSV 會吃掉）
✅ "他說：「沒問題」"       ← 用全形「」代替半形 ""
✅ "他說：""沒問題"""       ← 標準 CSV escape（用兩個雙引號代表 1 個）
```

### 陷阱 2：caption 含換行
```csv
✅ "第一段\n\n第二段"       ← 推薦：用 \n
✅ "第一段
第二段"                     ← 也 OK（Excel 內 Alt+Enter）
❌ "第一段\第二段"          ← 單 \ 不是換行符
```

### 陷阱 3：日期格式被 Excel 改掉
- Excel 預設會把 `2026-06-01 20:00` 改成 `2026/6/1 8:00 PM` 之類
- **解決**：把 scheduled_at 欄位格式預先設為「**文字**」
- 或在儲存格前面加 `'`：`'2026-06-01 20:00`（單引號告訴 Excel 「這是文字」）

### 陷阱 4：BOM
- Excel 存 CSV 預設加 UTF-8 BOM
- PuffinPuff 接受 BOM 與不含 BOM 兩種，但其他工具可能有問題
- 如果遇到問題，用 VS Code 開 → 右下角編碼點「UTF-8」（不是 UTF-8 with BOM）→ 重存

### 陷阱 5：filename 寫錯
- `001.JPG` 跟 `001.jpg` 在 Windows 大小寫不分，PuffinPuff OK
- 但**全形 vs 半形** 數字 / 英文要一致（`１.jpg` vs `1.jpg` 是不同檔名）
- 中文字元 OK（PuffinPuff 完整支援 UTF-8 路徑）

## PuffinPuff 偵測流程

當你拖入「含 manifest.csv」的資料夾：

1. **讀 manifest.csv** → 解析所有列
2. **檢查每列**：
   - filename 對應的圖檔存在？✅ / ❌
   - scheduled_at 是未來時間？✅ / ⚠️
   - platforms 至少 1 個有效平台？✅ / ❌
3. **預覽 UI 列出全部**：
   - ✅ 通過的 → 綠色，可確認排程
   - ⚠️ 有警告 → 黃色，需確認
   - ❌ 失敗的 → 紅色，自動跳過
4. **使用者確認** → 全部寫入 schedules 表 → flush DB → 註冊到 scheduler

## A 模式 vs B 模式：怎麼選？

| 情境 | 建議模式 |
|---|---|
| 30 篇都用「每日 20:00 發 FB+IG」 | A 模式（最簡單）|
| 30 篇要分散到不同時段 | B 模式 |
| 有些篇只發 FB、有些只發 IG | B 模式 |
| 怕學 CSV | A 模式 |
| Excel / Google Sheets 用很熟 | B 模式 |
| 客戶代操要交付排程表 | B 模式（CSV 也能當交付物）|
| 一次性快速發布 | A 模式 |
| 長期經營 1-3 個月內容 | B 模式（含時間規劃）|
